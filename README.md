## About this site

A single-page site written in plain HTML, CSS and JavaScript, with no frameworks or build step.

- Dark mode by default, with a light mode toggle that remembers each visitor's choice
- Animated network background that drifts as you scroll and reacts to the cursor
- Typewriter headlines, scroll-reveal sections and hover effects
- Works on phones, tablets and desktops, and respects the "reduce motion" accessibility setting
- Hosted for free on GitHub Pages

### Updating the site

1. Edit `index.html` or replace `Jasper_Koh_CV.pdf`, keeping the same filename.
2. Commit the change to the `main` branch.
3. GitHub Pages republishes automatically within a couple of minutes.
